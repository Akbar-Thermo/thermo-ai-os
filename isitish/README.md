# Расчёт отопления (Isitish kalkulyatori)

Раздел «Расчёт отопления» в Thermo AI OS: сравнение электрокотла, теплового насоса и газового котла за отопительный сезон по тарифам Узбекистана (Ташкент) и инфографика для клиента (PNG / PDF, узбекский и русский).

- `src/calc.js` — расчёт (тарифы `DEFAULT_TARIFFS`: ПКМ № 243 от 15.05.2026, с 01.06.2026), `i18n.js` — тексты, `render.js` — инфографика (SVG), `app.js` — форма, `style.css`.
- `python3 isitish/build.py` — собирает всё в `src/isitish.html`; раздел грузит этот файл отдельным куском только при открытии.
- `node isitish/test_calc.cjs` — проверка: дом 450 м² (56 / 36 кВт) → 128,4 / 77,0 / 40,9 / 24,6 млн сум.
- Расчёты, профиль менеджера и изменённые тарифы хранятся на устройстве (localStorage, ключи `isitish.v1.*`), в базу не пишутся.
