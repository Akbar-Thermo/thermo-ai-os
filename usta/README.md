# От мастеров (Usta ro'yxati)

Страница для мастеров: **/usta/** (без входа). Мастер пишет список материалов на телефоне — программа подсказывает товар,
продолжает слово, исправляет ошибки (латиница/кириллица/узбекские слова: «troynik 25 10 ta» → «Тройник ППР 25 — 10 шт»).
**Брендов и цен на странице нет** — только общие названия из словаря `src/vocab.js`.

- `src/vocab.js` — словарь: разделы, общие названия, синонимы, размеры, варианты (ВР/НР, 45°, тип 22…). Новый товар — одна строка в `ITEMS`.
- `src/engine.js` — распознавание строки (товар, вариант, размер, количество), `src/app.js` — страница, `i18n.js` — тексты (uz/ru), `style.css`.
- `python3 usta/build.py` — собирает всё в `public/usta/index.html` (адрес базы и публичный ключ берутся из `.env.txt`).
- `node usta/test_engine.cjs` — проверка распознавания на типичных строках мастеров.
- База: `supabase/usta/01_usta.sql` — таблица `usta_lists` (закрыта, как остальные) и функция `usta_submit` (единственный способ записи без входа: проверки, не больше 15 списков в час с одного номера).
- В программе: раздел **«От мастеров»** (у всех, у кого есть «Новая заявка»): ссылка для мастеров, новые списки (число на вкладке), «→ В новую заявку» — новая вкладка заявки, после выбора объекта позиции подбираются из базы, как при загрузке Excel.
- Черновик, имя/телефон и 10 последних отправленных списков мастер хранит у себя в телефоне (localStorage, ключи `usta.v1.*`).
