# Thermo AI OS — правила для Claude

## Прокрутка (обязательно, всегда)
Любое окно, список, панель или раздел крутится только сам. Когда прокрутка дошла до края
(или у окна своей прокрутки нет), то, что за ним, **не двигается вообще**.
Это касается компьютера (колёсико, тачпад), телефона и планшета (палец).

Как сделано (не ломать, новые окна должны попадать под это правило):
- `installWheelTrap()` (колёсико) и `installTouchTrap()` (палец) в `src/App.jsx`, общая проверка `scrollStopsHere()`.
- Всплывающее окно = класс из `WHEEL_ROOTS` или `position: fixed` (или `absolute` с z-index ≥ 10).
  Новое окно с другой разметкой — добавить его класс в `WHEEL_ROOTS` или атрибут `data-wheel-trap`.
- CSS `overscroll-behavior` — только на окнах (`.modal-bg`, `.npanel`, `.nwin`, `.calc`…) и списках с max-height (`.vt-box` и т.п.).
  **Никогда не ставить его на все элементы (`.te *`)**: Chrome перестаёт прокручивать страницу через любую таблицу
  с `overflow:auto` (Товары и Объекты не крутились, пока мышь над таблицей).
- Элемент, где палец должен работать свободно (рисование, ползунок), — атрибут `data-touch-free`.
- Горизонтальная лента, которая сама переводит колёсико в прокрутку вбок (например, мастера в «Объектах» — `MasterBar`),
  считается своим списком: у края ленты `preventDefault` всё равно, страница не двигается. Пропускать колесо странице
  можно только если лента целиком помещается (крутить нечего).

## Внешний вид (решения руководителя, ноябрь 2026 — не ломать)
- Офисная программа: фон нейтральный серый (светлая `#f5f5f5`, тёмная `#1b1b1d`, не чёрная), никакого цветового оттенка.
- Цвет — только со смыслом: синий (приглушённый `#2b6cb0` / тёмная `#3d78b8`) — главные кнопки и выбранный раздел;
  красный — долг, ошибка, удалить; жёлтый — предупреждение; зелёный — деньги/оплата. Без «ёлки»: статусы и метки —
  нейтральная плашка с цветной точкой, а не цветная заливка.
- Никаких «таблеток» (полностью круглых рамок): углы мягкие, `--r-pill` 6px, поля/кнопки 6px, карточки 8px, окна 10px.
- Никакого «свечения» (цветных теней) у кнопок и полей.
- Одно правило для всех элементов: нажатое / открытое / выбранное с клавиатуры — рамка чуть темнее серым (`var(--mut)`).
  Синей рамки при нажатии нет нигде. Выпадающие списки — как меню «Документы» (нейтральная рамка, те же углы).
- Кнопки и поля-выборы при нажатии «проседают» на 1px одинаково.
