# Thermo Engineering — procurement & finance OS

Система заявок, закупок, склада и финансового учёта Thermo Engineering.
Работает полностью вручную (без AI): подбор товаров из базы, объекты, поставщики, мастера, финансы.

## Как устроено
```
thermo-ai-os/
├─ src/
│  ├─ App.jsx    ← всё приложение
│  ├─ main.jsx   ← точка входа
│  └─ db.js      ← подключение к Supabase
├─ schema.sql    ← исходная структура таблиц (справочно)
├─ package.json, vite.config.js, index.html
└─ .env.example  ← шаблон ключей Supabase
```
- **Данные** — в Supabase (таблицы products, suppliers, objects, finance_ops, requests, masters, warehouse, wh_moves, users, audit_log).
- **Сайт** — на Vercel: каждый коммит в `main` автоматически собирается и публикуется (~1 минута). Данные при обновлении сайта не трогаются.
- **Валюта учёта** — доллар США. Оплаты в сумах вводятся с курсом и пересчитываются в $.

## Локальный запуск
```bash
npm install
npm run dev
```
Нужен файл `.env` с `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (см. `.env.example`).

## Роли
- **Руководитель** — всё, включая дашборд, журнал действий, аккаунты, бэкап и очистку базы, удаление операций.
- **Менеджер** — заявки, объекты, товары, склад, поставщики (с долгами и оплатами), мастера, финансы. Не видит дашборд с выручкой и прибылью, себестоимость в объектах; удалить может только объект без оплат.

## Разделы
Дашборд · Новая заявка (несколько заявок вкладками, загрузка списка из Excel) · Объекты (поставки, оплаты клиента разными способами, скидки, возвраты, Excel клиенту и лист доставки) · Товары (11 000+ позиций, импорт Excel, коды 1…N) · Склад Thermo · Поставщики (оплаты, акт сверки с выгрузкой в Excel) · Мастера (бонусы и выплаты) · Финансы (способы оплаты, расходы компании, долги) · Журнал действий · Аккаунты · Бэкап (скачать / восстановить, восстановление поставщиков у товаров, очистка базы).
